BirdBot guide

How to use the bot

Choose your server, open a feature, save your settings, and use BirdBot in Discord.

English

1. Sign in and choose a server

Open BirdBot and choose Open dashboard. Sign in with Discord, select your server, open the feature you want, change its settings, and press its save button. The website then applies the setting for that server in Discord.

  • Use Add the bot if BirdBot has not been invited yet.
  • Press Activate server and confirm the server. Activation enables dashboard features for that server; it does not restart the bot.
  • After changing a setting, press its save or setup button. Changes are sent to Discord immediately.

2. Commands

Open the Commands tab to choose the command prefix, turn prefix commands on or off, and choose English or Arabic replies for each command. Click a command to add optional shortcuts (for example, with ! as the prefix, pong becomes !pong).

For dashboard actions, choose the text channel and select the command or action you want. The bot needs permission to view the channel, send messages, embed links, and use components where applicable.

  • Commands configured here run only in the selected server.
  • If a command fails, check the bot role and the channel permission overwrites.

3. Server messages

In Control Panel → Server message, choose a channel, write the message, and decide whether it is a normal message or an embed. You can write naturally, mention members from the website picker, and select a message to reply to. The website sends it as BirdBot without needing an extra bot command.

  • Use a public channel that BirdBot can access.
  • Mentions notify the selected Discord member; always use them respectfully.
  • Replies keep the Discord message reference so the conversation appears threaded correctly.

4. Roles

Open Control Panel → Roles to create a role, set its name and color, and view the roles already in the server. Use edit to update a role or delete to remove it.

  • BirdBot cannot edit roles above its highest role.
  • Discord may reject deleting managed or protected roles.
  • Use a clear color and name so members can understand the role’s purpose.

5. Bot profile

Open Control Panel → Bot profile to set BirdBot’s nickname and avatar for this server only. These settings do not change the global Discord bot account.

  • Upload a PNG, JPEG, WebP, or GIF avatar up to 8 MB.
  • Leave the nickname blank to reset it, or remove the current server avatar.

6. DM’s messages

Open Control Panel → DM’s messages, choose a human server member, write a normal message or embed, and optionally insert mentions and attach one image or video.

  • Attachments are limited to 8 MB and are removed from the dashboard after delivery.
  • The recipient must allow direct messages from server members.
  • Use mentions carefully; only members selected in the website picker are notified.
  • Choose Everyone in the server to send the DM to all human members. When it finishes, the website reports delivered, failed, and skipped bot-account counts.
  • In Control Panel → Bot Settings, choose a channel and emoji to create an auto-react rule. You can add multiple rules for different channels, edit or disable them, and delete them independently.

7. Games

Open the Games tab and enable a game before using it in that server. Each game has a setup area. The selected language and options are stored per server, so Discord games start with the website settings and do not ask players for a language again.

  • Only an enabled game can create a lobby.
  • Use Setup to save the configuration, then try the game in Discord.
  • Games require the bot to be able to send messages and use buttons in the chosen channel.

8. Roulette

Roulette creates a lobby, lets players join, and spins a real animated wheel when the host starts. The wheel has one equal slice per player and uses the configured seven-color palette. The host can start once the minimum player count is reached.

  • Players join and leave from the lobby buttons; people outside the game cannot use player-only controls.
  • The lobby closes if it is not started before its timer expires.
  • Each turn has a configurable decision timer. If the current player does not choose, the game applies the timeout rule automatically.
  • Change the language and the seven slice colors in Roulette setup, then save.

9. Spy Game

Players join a lobby and the host starts it. Citizens receive the same private secret while one player is secretly the Spy. The role message is kept in one private message per player and is edited when it needs to refresh.

  • In each question turn, only the player asking the question can press Skip.
  • Manual End waits for every player to request a reveal, then starts the vote.
  • Auto End starts the vote after the configured number of rounds.
  • The vote has a timer. The final message clearly says The Spy Won or The Citizens Won, names the Spy, and labels the secret as either Location or Object.
  • Arabic uses the matching Arabic label for the selected secret type.

10. Music

Warning: The Music system is not working properly right now and is being fixed. You may still see the player, queue, pause, shuffle, loop, seek, and volume controls.

  • Open the Music page from the website, join a voice channel, and use the player controls.
  • Paste a song or audio link into the source box, then press play.
  • If playback fails, try again later while the system is being repaired.

العربية

١. تسجيل الدخول واختيار الخادم

افتح BirdBot واضغط فتح لوحة التحكم، ثم سجّل الدخول باستخدام Discord واختر خادمك. افتح الميزة المطلوبة، عدّل إعداداتها، ثم اضغط زر الحفظ ليطبّق الموقع التغيير في Discord لهذا الخادم.

  • استخدم إضافة البوت إذا لم تتم دعوة BirdBot إلى الخادم بعد.
  • اضغط تفعيل الخادم ثم أكّد الاختيار. التفعيل يفتح إعدادات الموقع ولا يعيد تشغيل البوت.
  • بعد تعديل أي إعداد، اضغط زر الحفظ أو الإعداد حتى يتم تطبيقه في Discord.

٢. الأوامر

افتح تبويب الأوامر، اختر القناة النصية، ثم اختر الأمر أو الإجراء. يحتاج البوت إلى صلاحيات رؤية القناة وإرسال الرسائل وإظهار الروابط واستخدام الأزرار عند الحاجة.

  • تعمل الإعدادات في الخادم الذي اخترته فقط.
  • إذا فشل الأمر، راجع دور البوت وصلاحيات القناة.

٣. رسائل الخادم

من لوحة التحكم ← رسالة الخادم اختر القناة واكتب الرسالة وحدد إن كانت رسالة عادية أو Embed. يمكنك الكتابة بشكل طبيعي، ومنشن الأعضاء باستخدام قائمة الموقع، واختيار رسالة للرد عليها. يرسلها الموقع باسم BirdBot من دون أمر إضافي في البوت.

  • اختر قناة يستطيع BirdBot الوصول إليها.
  • سيصل المنشن إلى عضو Discord المحدد، فاستخدمه باحترام.
  • يحافظ الرد على مرجع رسالة Discord ليظهر في المحادثة بشكل صحيح.

٤. الرتب

افتح لوحة التحكم ← الرتب لإنشاء رتبة وتحديد اسمها ولونها وعرض الرتب الموجودة في الخادم. يمكنك تعديل الرتبة أو حذفها.

  • لا يستطيع BirdBot تعديل رتبة أعلى من أعلى رتبة لديه.
  • قد يرفض Discord حذف الرتب المحمية أو المُدارة.
  • اختر اسماً ولوناً واضحين ليسهل فهم وظيفة الرتبة.

٥. ملف البوت

افتح لوحة التحكم ← ملف البوت لتغيير اسم BirdBot وصورته في هذا الخادم فقط. لا تغيّر هذه الإعدادات حساب البوت العام في Discord.

  • ارفع صورة PNG أو JPEG أو WebP أو GIF بحجم يصل إلى ٨ ميجابايت.
  • اترك الاسم فارغاً لإعادته إلى الاسم الافتراضي، أو احذف صورة الخادم الحالية.

٦. رسائل الخاص

افتح لوحة التحكم ← رسائل الخاص واختر عضواً بشرياً، ثم اكتب رسالة عادية أو Embed، ويمكنك إضافة منشن وإرفاق صورة أو فيديو.

  • حجم المرفق ٨ ميجابايت كحد أقصى، ويتم حذفه من لوحة التحكم بعد الإرسال.
  • يجب أن يسمح المستلم بالرسائل الخاصة من أعضاء الخادم.
  • استخدم المنشن بحذر؛ يتم إشعار الأعضاء الذين اخترتهم فقط.

٧. الألعاب

افتح تبويب الألعاب وفعّل اللعبة قبل استخدامها في الخادم. لكل لعبة قسم إعداد خاص بها. تُحفظ اللغة والإعدادات لكل خادم، لذلك تبدأ اللعبة في Discord بالإعدادات التي اخترتها من الموقع ولا تطلب من اللاعبين اختيار اللغة مرة أخرى.

  • لا يمكن إنشاء ردهة للعبة غير مفعّلة.
  • اضغط Setup لحفظ الإعداد ثم جرّب اللعبة في Discord.
  • تحتاج الألعاب إلى صلاحية إرسال الرسائل واستخدام الأزرار في القناة.

٨. روليت

تنشئ روليت ردهة للّاعبين وتعرض عجلة حقيقية متحركة عند بدء المضيف. لكل لاعب جزء متساوٍ، وتستخدم العجلة لوحة الألوان السبعة التي حددتها. يستطيع المضيف البدء عند الوصول إلى الحد الأدنى.

  • ينضم اللاعبون ويغادرون من أزرار الردهة، ولا يستطيع من هو خارج اللعبة استخدام أزرار اللاعبين.
  • تُغلق الردهة إذا لم يبدأها المضيف قبل انتهاء المؤقت.
  • لكل دور مؤقت قرار قابل للتعديل. إذا لم يختر اللاعب الحالي، يطبّق النظام قاعدة انتهاء الوقت تلقائياً.
  • غيّر اللغة وألوان الأجزاء السبعة من إعدادات روليت ثم احفظ.

٩. لعبة الجاسوس

ينضم اللاعبون إلى الردهة ويبدأها المضيف. يحصل المواطنون على السر نفسه في رسائل خاصة، بينما يكون لاعب واحد هو الجاسوس سراً. يحتفظ النظام برسالة خاصة واحدة لكل لاعب ويعدّلها عند الحاجة بدلاً من إنشاء رسائل متكررة.

  • في دور السؤال، يستطيع اللاعب الذي يطرح السؤال فقط الضغط على تخطي.
  • إنهاء يدوي ينتظر طلب الكشف من جميع اللاعبين ثم يبدأ التصويت.
  • إنهاء تلقائي يبدأ التصويت بعد عدد الجولات الذي حددته.
  • للتصويت مؤقت. تعرض النتيجة بوضوح «فاز الجاسوس» أو «فاز المواطنون»، مع اسم الجاسوس وتصنيف السر بدقة إلى الموقع أو الغرض.
  • يستخدم النظام تسمية عربية واحدة تطابق نوع السر المختار.

١٠. الموسيقى

تحذير: نظام الموسيقى لا يعمل بشكل صحيح حالياً ويجري إصلاحه. قد تظهر أزرار التشغيل والإيقاف المؤقت والعشوائي والتكرار والتقديم والتحكم بالصوت.

  • افتح صفحة الموسيقى من الموقع، وانضم إلى قناة صوتية، ثم استخدم أزرار المشغل.
  • الصق رابط الأغنية أو الصوت في مربع المصدر ثم اضغط تشغيل.
  • إذا فشل التشغيل، حاول لاحقاً أثناء إصلاح النظام.
