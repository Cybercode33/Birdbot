BirdBot guide

How to use BirdBot

Choose a server, open a section, save your settings, and use BirdBot in Discord.

English

1. Dashboard and server selection

Choose Open dashboard, sign in with Discord, and select a server. Press Activate server before using its management tools.

  • Use Add the bot if BirdBot is not in the server yet.
  • Activation applies dashboard settings to that server only; it does not restart the bot.
  • Save each form after editing it. The website reports when a change is queued or applied.
  • Open the Profile portal to review your recorded messages, image shares, voice time, and most active server.

2. Commands

Open the Commands tab to enable or disable prefix commands, set any prefix, and choose English or Arabic replies for each command. Open a command card to see its usage, options, permissions, and shortcuts.

  • Save shortcuts one at a time; add more whenever you need them. A shortcut works by itself and runs the command it belongs to.
  • Moderation commands include /kick, /ban, /warning, /unwarning, /show warning, /timeout, /untimeout, /mute, /unmute, /lock, /unlock, and /delete. Use /show level to generate a shareable level card.
  • /mute blocks the selected member from sending messages in the selected text channel only; it does not mute voice audio. Use /unmute to restore chat access.
  • Commands are configured per server. The bot still needs the Discord permissions shown on the command card.

3. Server message

Open Control Panel → Server message, choose a channel, select Normal message or Embed message, write the content, and press Send message.

  • Use the member picker to insert a mention, or paste a Discord message link to reply to it.
  • BirdBot must be able to view the channel, send messages, and embed links when an embed is used.

4. Ticket system

Open Ticket system to build the support panel members will use. Choose the panel channel, ticket category, support roles, priority, open-ticket limit, and Buttons Mode or Select Menu Mode.

  • Add support topics with a label, value, description, emoji, and button color when using Buttons Mode.
  • You can require a description and upload a custom panel icon.
  • Press Save ticket settings, then Post to publish the panel. Show Tickets and Ticket Logs open existing ticket records and history.

5. Logs

Open Logs to turn activity logging on or off. Each log type can use its own channel, so voice activity does not have to share a channel with message or moderation logs.

  • Enable the streams you need: Voice, Messages, Server, Members, and Moderation.
  • Voice logs include joins, leaves, moves, disconnects, server mute, and deafen changes.
  • Message logs include sent, edited, and deleted messages. Member logs include joins, leaves, and profile or role changes.
  • Moderation logs include kick, ban, unban, warning, unwarning, and timeout actions. Logs mention the user, action, and related channel or room when available.
  • Use Create Channel beside any log type to create and assign a private administrator-only Discord channel automatically.

6. Roles and permissions

Open Control Panel → Roles to create or edit a role. Set its name, color, and Discord permissions directly from the website, then save.

  • Permissions are grouped into messages and channels, server management, members and profile, and voice and apps.
  • BirdBot cannot edit roles above its highest role. Discord also protects managed roles.

7. Bot Profile

Open Control Panel → Bot profile to change BirdBot’s nickname and avatar in the selected server. This does not change the global bot account.

  • Supported avatar files are PNG, JPEG, WebP, and GIF up to 8 MB.
  • Leave the nickname blank to reset it.

8. DM’s Messages

Open Control Panel → DM’s Messages, choose one member or Everyone in the server, then select Normal message or Embed message.

  • Add mentions and attach one image or video up to 8 MB.
  • For a broadcast, the website reports how many messages were delivered, failed, or skipped.
  • Recipients must allow direct messages from server members. Send private messages responsibly.

9. Bot Settings

Open Control Panel → Bot Settings to configure Automod, automatic reactions, and the optional AI assistant. Turn on the feature you need, choose its settings, and press the matching save button.

  • Available rules are Anti-link, Anti-spam, Banned words filter, Raid protection, Auto-warning, and Auto-timeout.
  • Use the threshold fields for spam, raid joins, timeout length, and your banned-word list. Rules only affect new activity after they are saved.
  • Add an auto-react rule by choosing a channel and emoji. Multiple channels can have separate rules; each rule can be edited, disabled, or removed.
  • If AI is available, enable AI assistant, choose one response channel, and save. BirdBot replies to every human message in that channel; messages elsewhere are ignored.
  • Open Control Panel → Level to enable activity leveling, choose one of four progression styles, select English or Arabic announcements, and review top-level and daily/weekly activity leaderboards.

10. Members

On Your servers, press Show Members to view server members and details such as their join date. Use the member action buttons for Kick, Ban, or Timeout.

  • Bulk actions are available as Kick All, Ban All, and Timeout All; review the confirmation before using them.
  • Discord permissions and role hierarchy still apply to every action.

11. Games

Open Games, enable a game, configure its language and options, and press Setup. Choose a lobby channel before starting a game in Discord.

  • Players use the lobby buttons to join or leave. The host starts the game when the minimum player count is met.
  • BirdBot needs permission to view the selected channel, send messages, and use buttons.

12. Roulette

Roulette gives each player an equal slice and spins the configured wheel when the host starts. Configure the language, seven slice colors, minimum players, and timers in the Roulette setup.

  • Players use Join and Leave. Turn timers apply the configured timeout rule automatically.
  • The lobby expires if the host does not start it in time.

13. Spy Game

Players join the lobby and the host starts the game. Citizens receive the same secret privately, while one player is secretly the Spy. Each player’s role message is edited instead of sending repeated messages.

  • Use the configured Manual End or Auto End mode to begin the vote.
  • The result names the winner and labels the secret precisely as a Location or an Object.

14. Guess the Number

Start a lobby from the Guess the Number game panel. Players use Join and Leave, then the host presses Start. There is no slash command for guessing.

  • After the lobby starts, press Guess number and submit one guess per round.
  • The game shows who has finished and how many players remain. If nobody is correct, it starts the next round with a higher, lower, or range hint.
  • If the final range identifies the number, the game announces the number and all matching winners, then resets cleanly for the next stage.

15. VC (premium)

VC is a premium control-panel feature for placing secure presence bots in voice channels. If your account has access, choose a voice channel for each available slot and save the placement.

  • Each bot can be placed or removed independently.

العربية

١. لوحة التحكم واختيار الخادم

اضغط فتح لوحة التحكم وسجّل الدخول باستخدام Discord ثم اختر الخادم. اضغط تفعيل الخادم قبل استخدام أدوات الإدارة.

  • استخدم إضافة البوت إذا لم تتم دعوة BirdBot إلى الخادم.
  • يطبّق التفعيل إعدادات لوحة التحكم على هذا الخادم فقط ولا يعيد تشغيل البوت.
  • احفظ كل نموذج بعد تعديله؛ سيعرض الموقع حالة الحفظ أو التنفيذ.

٢. الأوامر

افتح تبويب الأوامر لتفعيل أو تعطيل أوامر البادئة، وكتابة أي بادئة، واختيار الردود بالعربية أو الإنجليزية لكل أمر. افتح بطاقة الأمر لرؤية طريقة الاستخدام والخيارات والصلاحيات والاختصارات.

  • احفظ كل اختصار وحده، ويمكنك إضافة اختصارات أخرى لاحقاً. يعمل الاختصار بمفرده وينفّذ الأمر المرتبط به.
  • تشمل أوامر الإدارة /kick و/ban و/warning و/unwarning و/show warning و/show level و/timeout و/untimeout و/mute و/unmute و/lock و/unlock و/delete.
  • يمنع /mute العضو المحدد من إرسال الرسائل في القناة النصية المختارة فقط، ولا يكتم الصوت. استخدم /unmute لإعادة الوصول إلى الدردشة.
  • تُحفظ الأوامر لكل خادم، ويحتاج البوت إلى صلاحيات Discord الموضحة في بطاقة الأمر.

٣. رسالة الخادم

من لوحة التحكم ← رسالة الخادم اختر القناة وحدد رسالة عادية أو رسالة Embed واكتب المحتوى ثم اضغط إرسال الرسالة.

  • استخدم قائمة الأعضاء لإضافة منشن، أو الصق رابط رسالة Discord للرد عليها.
  • يحتاج BirdBot إلى رؤية القناة وإرسال الرسائل وإظهار الروابط عند استخدام Embed.

٤. نظام التذاكر

افتح نظام التذاكر لبناء لوحة الدعم التي سيستخدمها الأعضاء. اختر قناة اللوحة وفئة التذاكر وأدوار الدعم والأولوية وحد التذاكر، ثم اختر وضع الأزرار أو وضع القائمة.

  • أضف موضوعات الدعم مع الاسم والقيمة والوصف والإيموجي ولون الزر في وضع الأزرار.
  • يمكنك طلب وصف عند فتح التذكرة ورفع أيقونة مخصصة للوحة.
  • اضغط حفظ إعدادات التذاكر ثم نشر. تعرض إظهار التذاكر وسجلات التذاكر التذاكر والتاريخ.

٥. السجلات

افتح السجلات لتفعيل تسجيل النشاط أو تعطيله. يمكنك اختيار قناة مختلفة لكل نوع، لذلك لا يلزم وضع سجلات الصوت والرسائل والإدارة في قناة واحدة.

  • فعّل ما تحتاجه: الصوت والرسائل والخادم والأعضاء والإدارة.
  • تسجل سجلات الصوت الانضمام والمغادرة والنقل والفصل والكتم وكتم السماعة.
  • تسجل سجلات الرسائل الإرسال والتعديل والحذف، وتسجل سجلات الأعضاء الانضمام والمغادرة وتغييرات الملف أو الرتب.
  • تشمل سجلات الإدارة الطرد والحظر وإلغاء الحظر والتحذير وإلغاء التحذير والإسكات المؤقت، وتذكر المستخدم والإجراء والقناة أو الغرفة عند الإمكان.

٦. الرتب والصلاحيات

افتح لوحة التحكم ← الرتب لإنشاء رتبة أو تعديلها. حدّد الاسم واللون وصلاحيات Discord مباشرة من الموقع ثم احفظ.

  • تجمع الصلاحيات الرسائل والقنوات، وإدارة الخادم، والأعضاء والملف، والصوت والتطبيقات.
  • لا يستطيع BirdBot تعديل رتبة أعلى من أعلى رتبة لديه، وتحمي Discord الرتب المُدارة.

٧. ملف البوت

افتح لوحة التحكم ← ملف البوت لتغيير اسم BirdBot وصورته في الخادم المحدد فقط. لا يغيّر ذلك حساب البوت العام.

  • الصور المدعومة PNG وJPEG وWebP وGIF بحجم أقصاه ٨ ميجابايت.
  • اترك الاسم فارغاً لإعادته إلى الاسم الافتراضي.

٨. رسائل الخاص

افتح لوحة التحكم ← رسائل الخاص واختر عضواً واحداً أو الجميع في الخادم، ثم حدد رسالة عادية أو رسالة Embed.

  • أضف منشن وأرفق صورة أو فيديو بحجم أقصاه ٨ ميجابايت.
  • عند الإرسال للجميع يعرض الموقع عدد الرسائل التي وصلت وفشلت وتم تجاوزها.
  • يجب أن يسمح المستلم بالرسائل الخاصة من أعضاء الخادم؛ استخدم الإرسال بمسؤولية.

٩. إعدادات البوت

افتح لوحة التحكم ← إعدادات البوت لإعداد Automod والتفاعلات التلقائية والمساعد الاختياري بالذكاء الاصطناعي. فعّل الميزة المطلوبة، اختر إعداداتها، ثم اضغط زر الحفظ المناسب.

  • القواعد المتاحة: منع الروابط، منع التكرار، الكلمات المحظورة، حماية الغارات، التحذير التلقائي، والإسكات التلقائي.
  • استخدم حدود الرسائل والغارات ومدة الإسكات وقائمة الكلمات. تبدأ القواعد بعد الحفظ ولا تفحص الرسائل القديمة.
  • أضف تفاعلاً تلقائياً باختيار قناة وإيموجي. يمكن إنشاء قواعد متعددة لقنوات مختلفة وتعديل كل قاعدة أو تعطيلها أو حذفها.
  • إذا كان المساعد متاحاً، فعّل المساعد الذكي واختر قناة الرد ثم احفظ. سيرد BirdBot على كل رسالة من مستخدم في تلك القناة، ويتجاهل الرسائل في القنوات الأخرى.

١٠. الأعضاء

في صفحة خوادمك اضغط إظهار الأعضاء لعرض أعضاء الخادم وتفاصيل مثل تاريخ الانضمام. استخدم أزرار الطرد أو الحظر أو الإسكات المؤقت.

  • تتوفر إجراءات جماعية: طرد الجميع وحظر الجميع وإسكات الجميع؛ راجع التأكيد قبل استخدامها.
  • تظل صلاحيات Discord وترتيب الرتب مطبقة على كل إجراء.

١١. الألعاب

افتح الألعاب وفعّل اللعبة، ثم اضبط اللغة والإعدادات واضغط Setup. اختر قناة الردهة قبل بدء اللعبة في Discord.

  • يستخدم اللاعبون أزرار الانضمام والمغادرة، ويبدأ المضيف عند الوصول إلى الحد الأدنى.
  • يحتاج BirdBot إلى صلاحية رؤية القناة وإرسال الرسائل واستخدام الأزرار.

١٢. روليت

تعطي روليت كل لاعب جزءاً متساوياً وتدير العجلة عند بدء المضيف. اضبط اللغة وألوان الأجزاء السبعة وعدد اللاعبين والمؤقتات.

  • يستخدم اللاعبون انضمام ومغادرة، وتطبّق المؤقتات قاعدة انتهاء الدور تلقائياً.
  • تنتهي الردهة إذا لم يبدأها المضيف خلال الوقت المحدد.

١٣. لعبة الجاسوس

ينضم اللاعبون إلى الردهة ويبدأها المضيف. يحصل المواطنون على السر نفسه في رسائل خاصة ويكون لاعب واحد هو الجاسوس. تعدّل رسالة دور كل لاعب بدلاً من إرسال رسائل متكررة.

  • استخدم وضع الإنهاء اليدوي أو التلقائي المحدد لبدء التصويت.
  • تعلن النتيجة الفائز وتسمّي السر بدقة: الموقع أو الغرض.

١٤. خمن الرقم

ابدأ الردهة من إعدادات لعبة خمن الرقم. يستخدم اللاعبون انضمام ومغادرة ثم يضغط المضيف بدء. لا يوجد أمر شرطة مائل للتخمين.

  • بعد بدء الردهة اضغط خمن الرقم وأرسل تخميناً واحداً في كل جولة.
  • يعرض النظام من انتهى وعدد اللاعبين المتبقين. إذا لم يصب أحد، تبدأ الجولة التالية مع تلميح أعلى أو أقل أو نطاق.
  • إذا حدّد النطاق الرقم، يعلن النظام الرقم والفائزين المطابقين ثم يعيد ضبط اللعبة بسلاسة للمرحلة التالية.

١٥. VC (ميزة مدفوعة)

VC ميزة مدفوعة في لوحة التحكم لوضع بوتات حضور آمنة في القنوات الصوتية. إذا كان حسابك يملك صلاحية الوصول، اختر قناة صوتية لكل خانة ثم احفظ.

  • يمكن وضع كل بوت أو إزالته بشكل مستقل.
